# Reporte de Pruebas - Postman

Esta carpeta contiene las capturas de pantalla de las pruebas realizadas en Postman para cada operación del CRUD.

## Capturas requeridas:

1. **GET** - Obtener todos los usuarios
2. **GET** - Obtener usuario por ID
3. **POST** - Crear nuevo usuario
4. **PUT** - Actualizar usuario
5. **DELETE** - Eliminar usuario

## Instrucciones:
1. Ejecutar el microservicio con `npm run dev`
2. Abrir Postman
3. Probar cada endpoint
4. Tomar captura de pantalla de cada operación
5. Guardar las imágenes en esta carpeta
